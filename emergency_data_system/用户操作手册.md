# 用户操作手册

## 怎么装

### Docker（推荐，一行命令）

```bash
docker-compose up -d
```

然后浏览器打开 `http://localhost:5000`

### 手动跑

1. 电脑要有 Python 3.8 以上
2. 装依赖：`pip install -r requirements.txt`
3. 启动：`python app.py`
4. 浏览器打开 `http://127.0.0.1:5000`

## 怎么用

### 第一步：登录

右上角有登录框。默认账号 admin，密码 admin123。

第一次用的话，点旁边的"注册"按钮，填个自己的用户名和密码。推荐自己注册一个。

### 第二步：准备 Excel

把你要处理的表格准备好。系统支持 .xlsx 格式。

你的 Excel 里大概会有这些列（叫法不用完全一样，系统能认）：

- 企业名称（写成"企业""公司""单位"都行）
- 联系电话（"手机""电话""手机号"也能认）
- 排查日期（"日期""检查日期"也行）
- 企业地址（"地址""所在地"都可以）
- 排查类型、隐患等级

不确定格式的话，上传区下面有个"下载示例模板"的链接，下一份照着改就行。

### 第三步：上传清洗

1. 点上传区选文件（或者直接拖进去）
2. 点"一键智能清洗"
3. 等一两秒就完了

### 第四步：看结果

洗完会出来几样东西：

- 顶上四个数字卡片：原始多少条、有效多少条、删了多少重复的、多少条有问题
- 柱状图：四根柱子对比着看
- 饼图：异常类型占比
- 排查类型分布：安全生产多少条、消防检查多少条
- 隐患等级构成：一般/较大/重大各占多少
- 最下面是个表格：每条异常的具体信息，谁出问题了、怎么回事

### 第五步：下载

三个下载按钮：

- **下载清洗后报表**——处理完的 Excel，空的格子会标成"待补充"而且是橙色字
- **下载异常日志**——所有问题数据的清单
- **下载完整报表**——上面的东西打包到一个文件里，三个 Sheet

## 它帮你做了什么

上传之后系统自动干的活：

- 把乱七八糟的列名统一了（不用你手动对齐表头）
- 日期全改成 2024-01-05 这种格式（不管原来写成啥样）
- 手机号校验——错的给你标出来
- 重复的记录删掉（同一家企业同一天只算一次）
- 空的格子填上"待补充"（打开 Excel 一看橙色字的就知道要补）

## 数据看板

登录之后，页面底部还有两个东西：

- 全局统计：总共处理了多少数据、异常率多少
- 月度趋势：每个月处理量变化的折线图

如果你传过好几次文件，这里就能看到历史变化了。

## 数据管理

点"清空我的数据"可以把自己账号下的东西全删了。只删自己的，不影响别人。

## 常见问题

**Q：传不上去，提示格式不对？**

A：只认 .xlsx。如果是 .xls 旧格式，用 Excel 打开另存一下。

**Q：洗完发现少了几条？**

A：那是重复的被自动去掉了。看异常日志能知道哪些被处理了。

**Q：为什么提示"请先登录"？**

A：上传和下载都要登录。右上角登录一下就行。

**Q：能好几个人用吗？**

A：一个电脑上跑起来，大家浏览器各自登录就行。每个人的数据互不干扰。
