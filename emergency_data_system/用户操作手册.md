# 应急数据清洗与可视化系统 — 用户操作手册

> **版本：** v1.0  
> **适用对象：** 基层应急管理工作人员

---

## 一、系统简介

本系统是一款浏览器端的 Excel 数据清洗工具，帮助您快速完成以下工作：

- 将各乡镇、科室上报的零散 Excel 报表自动统一格式
- 自动找出错误电话号码、缺失数据、重复记录
- 生成可视化图表，直观呈现排查数据态势
- 一键导出标准化报表，直接用于上报和存档

---

## 二、安装与启动

### 方式一：Docker 一键启动（推荐）

1. 确保电脑已安装 Docker
2. 在项目目录下执行：
```
docker-compose up -d
```
3. 打开浏览器访问 `http://localhost:5000`

### 方式二：手动启动

1. 确保电脑已安装 Python 3.8+
2. 安装依赖：
```
pip install -r requirements.txt
```
3. 启动系统：
```
python app.py
```
4. 打开浏览器访问 `http://127.0.0.1:5000`

## 三、快速入门

### 3.1 登录系统

1. 打开浏览器访问系统地址
2. 在页面右上角输入用户名和密码
3. 点击「登录」按钮

> **默认管理员账号：** admin / admin123  
> **首次登录后建议注册自己的账号：** 点击「注册」按钮，填写用户名和密码即可

### 3.2 准备 Excel 文件

系统接受 `.xlsx` 格式的 Excel 文件。您的表格应包含以下常见列名中的任意一种：

| 数据类别 | 支持的列名 |
|---------|-----------|
| 企业名称 | 企业、公司、单位、企业名、公司名称、单位名称 |
| 联系电话 | 手机、电话、手机号、联系电话、联系号码 |
| 排查日期 | 日期、排查时间、检查日期、上报日期 |
| 企业地址 | 地址、所在地、公司地址、详细地址 |
| 排查类型 | 排查类型、检查类型 |
| 隐患等级 | 隐患、风险等级、隐患级别 |

> **提示：** 不确定格式？在系统上传页面点击「下载示例模板」获取标准格式文件。

### 3.3 上传并清洗数据

1. 点击上传区域，选择您的 Excel 文件（或直接拖拽文件到上传区）
2. 点击「一键智能清洗」按钮
3. 等待 1-2 秒，系统自动完成清洗

### 3.4 查看清洗结果

清洗完成后，页面会显示：

- **统计卡片：** 原始条数、有效条数、剔除重复数、异常条数
- **清洗总览图：** 柱状图对比原始/有效/剔除/异常数据量
- **异常分布图：** 饼图展示各类异常占比
- **排查类型分布：** 柱状图展示安全生产、消防检查等各类型数量
- **隐患等级构成：** 环形图展示一般/较大/重大隐患占比
- **异常日志表：** 每条异常的行号、字段、原始值、处理方式

### 3.5 下载报表

清洗完成后，可以下载以下文件：

| 按钮 | 内容 |
|------|------|
| 下载清洗后报表 | 标准化 Excel 文件，"待补充"项已橙色标注 |
| 下载异常日志 | 所有异常数据的明细清单 |
| 下载完整报表 | 包含清洗数据+异常日志+统计汇总的三合一报表 |

## 四、功能详解

### 4.1 数据清洗规则

系统自动执行以下清洗操作：

1. **统一字段名：** 把"企业""公司""单位"自动统一为"企业名称"
2. **规范日期格式：** 把 2024/1/5、2024年1月5日、20240105 等格式统一为 2024-01-05
3. **校验电话号码：** 自动清除空格和横线，检查号码是否合法
4. **规整企业名称：** 清除多余空格，统一括号格式
5. **补全地址：** 自动添加省/市/区前缀
6. **去除重复：** 同一企业同一天的重复记录自动剔除
7. **补充缺失：** 空白字段自动填"待补充"并在报表中橙色标注

### 4.2 历史数据看板

登录后，页面底部会显示：

- **全局数据概览：** 累计处理记录数、整体异常率、历史批次数
- **月度数据趋势：** 折线图展示各月份数据处理量变化

### 4.3 数据管理

- **清空数据：** 登录后点击「清空我的数据」按钮可清除本账号的所有数据
- **多账户隔离：** 不同用户的数据互不可见，各自管理

### 4.4 用户管理（管理员）

管理员可以：
- 创建新用户：点击「注册」按钮
- 查看所有用户：通过 `/auth/users` 接口
- 清理指定数据：通过 `/api/admin/cleanup` 接口

## 五、常见问题

**Q：上传文件后提示"不支持的文件格式"？**
A：系统仅支持 `.xlsx` 格式。如果是 `.xls` 格式，请用 Excel 打开后另存为 `.xlsx`。

**Q：清洗后有些数据不见了？**
A：系统会自动剔除重复记录（同一企业同一天只保留一条）。查看异常日志可了解具体哪些数据被处理。

**Q："待补充"是什么意思？**
A：表示原始数据中该字段为空，系统已自动填充占位符。请在报表中找到橙色标注的单元格进行人工补录。

**Q：提示"请先登录"？**
A：系统的上传和查询功能需要登录后才能使用。点击右上角输入账号密码登录。

**Q：能多人同时使用吗？**
A：当前版本为单机部署，支持浏览器多标签页登录不同账号使用。大规模多用户场景需部署数据库版。
