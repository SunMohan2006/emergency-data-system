# 软件设计说明书

## 这软件是干嘛的

基层应急管理局日常要处理大量 Excel 报表——乡镇报的、科室报的、企业报的，格式乱七八糟。人工整理一搞就是几个小时，还容易出错。我就做了个网页工具，把 Excel 丢进去，自动洗干净、出图表、能下载。

主要用到的技术：Python + Flask + Pandas + ECharts。选这套东西是因为轻，不用装数据库就能跑，普通办公电脑直接 `python app.py` 就行。

## 怎么搭起来的

整个系统分了三层，其实说白了就是：

1. **前端页面**——就是浏览器里看到的那个界面，上传文件、看图表、下载报表都在这里
2. **Flask 后端**——接收前端请求，调清洗引擎，返回结果。一共写了 10 个接口
3. **清洗引擎**——核心部分，读 Excel、统一列名、校验数据、去重、生成日志，全在这

```
浏览器 → Flask → Pandas清洗 → 返回结果
                ↓
            SQLite存一份（关了浏览器数据也不丢）
```

## 每个文件干什么的

| 文件 | 干啥的 |
|------|--------|
| app.py | Flask 主程序，管路由和接口 |
| data_cleaner.py | 清洗引擎，六百多行，最核心 |
| config.py | 配置文件，字段映射、规则参数都在这里改 |
| database.py | 数据库操作，用的 SQLAlchemy，默认 SQLite |
| auth.py | 登录注册，密码哈希存的 |
| report.py | 导出格式化报表，多 Sheet 的那种 |
| charts.js | 前端交互逻辑，上传、图表渲染、登录 |
| index.html | 页面结构 |

## 清洗引擎怎么工作的

我把它拆成了 9 个步骤，一步一步走：

1. 读 Excel——用 Pandas 读进来，全空的行和列自动删掉
2. 统一定名——比如"企业""公司""单位"全改成"企业名称"，"手机""电话"改成"联系电话"
3. 日期处理——各种写法（2024/1/5、2024年1月5日、20240105）统一成 2024-01-05
4. 电话校验——去掉空格横线括号，看是不是合法手机号或固话，不合法的记下来
5. 名称规整——去空格、统一全半角括号、空值的标出来
6. 地址补全——如果配置了省市区前缀，自动补上去
7. 去重——同一家企业同一天只保留一条，重复的删掉
8. 填空白——空的格子统一填"待补充"，后面在 Excel 里用橙色标出来
9. 出报表——生成清洗后的 Excel 和异常日志

第 9 步还有一个细节：输出的 Excel 里，所有"待补充"的格子都是橙色加粗字体，一眼就能看到哪些需要补。

## 数据库设计

两个表：

**clean_records（清洗记录）**
- user_id——哪个用户的
- batch_id——哪一批洗的
- company_name、phone、check_date、address、check_type——清洗后的数据
- is_anomaly——这条是不是异常数据
- created_at——什么时候存的

**anomaly_records（异常日志）**
- user_id、batch_id——关联到哪一批
- excel_row、field_name、original_value、anomaly_type、solution——异常详情

不用 MySQL 也能跑——默认 SQLite，文件存在本地。想换 MySQL 的话改个环境变量就行。

## 用户怎么登录的

没用什么第三方登录库，直接用 Flask 自带的 session。密码存的时候用 werkzeug 的 generate_password_hash 哈希过，不是明文。默认有个 admin 账号，密码 admin123。

角色分两种：
- admin：能创建用户、删数据
- operator：只能上传清洗、看自己的数据

## 报表长什么样

下载的完整报表有三个 Sheet：

1. 清洗数据——洗干净的表格，表头深蓝白字，冻结了首行方便翻看
2. 异常日志——每条异常信息，类型用颜色标签区分
3. 统计汇总——原始多少条、有效多少条、有效率多少，一眼看明白

## 测试怎么做的

54 个测试用例，用的 pytest。分成两块：
- 37 个测清洗引擎——日期解析、电话校验、去重逻辑、空文件处理，全测了
- 17 个测 API——登录、上传、权限、安全防护（路径穿越什么的）

每次 push 代码到 GitHub，Actions 自动跑一遍测试。

## 安全方面

- 数据全在本地，没有任何往外传的逻辑
- 上传只认 .xlsx，大小限制 10MB
- 下载文件做了防路径穿越（basename 处理）
- 密码哈希存，不存明文
- 不同用户的数据互相看不到

## 部署

两种方式：

1. Docker：`docker-compose up -d`，一分钟搞定
2. 手动：装依赖，`python app.py`，浏览器打开 5000 端口
